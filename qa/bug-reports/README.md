# Bug reports

One file per defect, named `BUG-0xx.md`, following `../bug-report-template.md`.

No numbered reports are filed here yet. What the test pass actually found is
written up in `../../RESULTS.md` and `../../FAILURES.md`, and the observations
that did not meet the bar for a report are in `../notes.md`.

The distinction matters: a report in this folder is a claim that something is
broken in the product, with steps to reproduce it. The material in `RESULTS.md`
is mostly a claim about an agent's behaviour under test, which is a different
thing and belongs where it is.
